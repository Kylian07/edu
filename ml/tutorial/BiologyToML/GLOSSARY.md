# 📘 Glossary

Short definitions of the terms used across **BiologyToML**. *First met in* links to the earliest module whose text uses
the term; *Explained in* links to the module that teaches it in depth, usually with an equation, its plain-language
reading and code. Module numbers refer to the [roadmap](README.md#roadmap).

| Term | Meaning | First met in | Explained in |
|---|---|---|---|
| **Accuracy** | Fraction of predictions that are correct. Misleading when classes are unbalanced; report precision and recall too. | [00](notebooks/00_welcome_ml_for_biology.ipynb) | [08](notebooks/08_knn_naive_bayes.ipynb) |
| **Activation function** | The non-linear function a neuron applies to its weighted input: sigmoid, tanh or ReLU (max(0, z)). | [22](notebooks/22_neural_networks.ipynb) | [22](notebooks/22_neural_networks.ipynb) |
| **Active / inactive path** | In d-separation, a path along which dependence can (active) or cannot (inactive) flow, given the observed variables. | [16](notebooks/16_bayesian_networks_independence.ipynb) | [16](notebooks/16_bayesian_networks_independence.ipynb) |
| **Adjusted Rand index (ARI)** | Agreement between two clusterings on pairs of samples, corrected for chance: 1 = identical, ≈ 0 = random. | [12](notebooks/12_clustering_kmeans_hierarchical.ipynb) | [13](notebooks/13_mixture_models_em.ipynb) |
| **ALL / AML** | Acute lymphoblastic and acute myeloid leukaemia, the two classes of the Golub et al. (1999) expression data. | [00](notebooks/00_welcome_ml_for_biology.ipynb) | [00](notebooks/00_welcome_ml_for_biology.ipynb) |
| **Allele, allele frequency** | One version of a DNA position (e.g. A or T at a SNP); its frequency is the fraction of chromosomes in a population that carry it. | [01](notebooks/01_python_numpy_for_biologists.ipynb) | [02](notebooks/02_probability_for_biologists.ipynb) |
| **Ancestral (forward) sampling** | Drawing a joint sample from a Bayesian network by sampling each variable after its parents, in topological order. | [13](notebooks/13_mixture_models_em.ipynb) | [17](notebooks/17_bayesian_networks_inference_learning.ipynb) |

| **Back-propagation** | Computing the gradient of the loss for every weight of a network by applying the chain rule backwards, layer by layer. | [04](notebooks/04_calculus_and_optimization.ipynb) | [22](notebooks/22_neural_networks.ipynb) |

| **Bayes error rate** | The error of the best possible classifier for a problem — the floor set by overlapping class distributions that no method can beat. | [08](notebooks/08_knn_naive_bayes.ipynb) | [23](notebooks/23_model_selection.ipynb) |
| **Bayes' rule** | P(A∣B) = P(B∣A)P(A)/P(B): turns the probability of the data given a hypothesis into the probability of the hypothesis given the data. | [01](notebooks/01_python_numpy_for_biologists.ipynb) | [02](notebooks/02_probability_for_biologists.ipynb) |
| **Bayesian information criterion (BIC)** | −2 log L̂ + k log n: rewards fit, penalises the number of parameters k; lower is better. | **Bayesian network** | A directed acyclic graph plus one conditional distribution per node; the joint distribution is the product of P(node ∣ parents). | [00](notebooks/00_welcome_ml_for_biology.ipynb) | [15](notebooks/15_bayesian_networks_representation.ipynb) |
| **Bernoulli distribution** | Distribution of a 0/1 variable with P(1) = q (carrier or not, head or tail). | [02](notebooks/02_probability_for_biologists.ipynb) | [02](notebooks/02_probability_for_biologists.ipynb) |
| **Bias (of an estimator or model)** | Systematic error: how far the average prediction or estimate (over many training sets) is from the truth. High bias = rigid model, high training error. | [00](notebooks/00_welcome_ml_for_biology.ipynb) | [23](notebooks/23_model_selection.ipynb) |
| **Bias–variance decomposition** | Expected squared test error = bias² + variance + irreducible noise; flexible models trade bias for variance. | [00](notebooks/00_welcome_ml_for_biology.ipynb) | [23](notebooks/23_model_selection.ipynb) |
| **Binomial distribution** | Number of successes in n independent Bernoulli trials; a genotype 0/1/2 is binomial with n = 2 under Hardy–Weinberg. | [01](notebooks/01_python_numpy_for_biologists.ipynb) | [02](notebooks/02_probability_for_biologists.ipynb) |

| **Bootstrap** | Resampling N samples with replacement from the data to mimic drawing a new data set; used for uncertainty and for bagging. | [07](notebooks/07_ridge_lasso_sparse_regression.ipynb) | [10](notebooks/10_decision_trees_random_forests.ipynb) |
| **Burn-in** | The first iterations of an MCMC chain, discarded because they still depend on the arbitrary starting point. | [21](notebooks/21_bayesian_learning_mcmc.ipynb) | [21](notebooks/21_bayesian_learning_mcmc.ipynb) |
| **Categorical (multinoulli) distribution** | Distribution of a variable with K possible values and probabilities summing to 1 (e.g. a genotype AA/AT/TT). | [02](notebooks/02_probability_for_biologists.ipynb) | [08](notebooks/08_knn_naive_bayes.ipynb) |
| **Central limit theorem** | Sums (or averages) of many small independent effects are approximately Gaussian — why polygenic traits look bell-shaped. | [02](notebooks/02_probability_for_biologists.ipynb) | [02](notebooks/02_probability_for_biologists.ipynb) |

| **Chain rule (probability)** | P(A, B, C) = P(A) P(B∣A) P(C∣A, B); any joint distribution can be factorised this way. | [02](notebooks/02_probability_for_biologists.ipynb) | [02](notebooks/02_probability_for_biologists.ipynb) |

| **Conditional independence** | X ⊥ Y ∣ Z: once Z is known, learning Y tells you nothing more about X. The key assumption of naïve Bayes, Bayesian networks and HMMs. | [00](notebooks/00_welcome_ml_for_biology.ipynb) | [02](notebooks/02_probability_for_biologists.ipynb) |
| **Conditional probability table (CPT)** | The table of P(node ∣ parents) for every combination of parent values in a discrete Bayesian network. | [02](notebooks/02_probability_for_biologists.ipynb) | [15](notebooks/15_bayesian_networks_representation.ipynb) |
| **Confusion matrix** | Table of true vs predicted classes; its cells are true/false positives/negatives. | [00](notebooks/00_welcome_ml_for_biology.ipynb) | [09](notebooks/09_logistic_regression.ipynb) |
| **Conjugate prior** | A prior that gives a posterior of the same family (Beta prior + binomial data → Beta posterior). | [05](notebooks/05_likelihood_mle_map.ipynb) | [21](notebooks/21_bayesian_learning_mcmc.ipynb) |
| **Convex / concave function** | A bowl (convex) or dome (concave): every local optimum is global. The logistic-regression log-likelihood is concave. | [03](notebooks/03_linear_algebra_for_data.ipynb) | [04](notebooks/04_calculus_and_optimization.ipynb) |

| **Correlation (Pearson)** | Covariance divided by both standard deviations, between −1 and 1; the cosine of the angle between centred vectors. | [02](notebooks/02_probability_for_biologists.ipynb) | [02](notebooks/02_probability_for_biologists.ipynb) |

| **Cross-validation (k-fold, LOOCV)** | Estimating test error by rotating which part of the training data is held out; LOOCV holds out one sample at a time. | [00](notebooks/00_welcome_ml_for_biology.ipynb) | [23](notebooks/23_model_selection.ipynb) |
| **d-separation** | A graphical test for conditional independence in a Bayesian network: X ⊥ Y ∣ Z if every path between X and Y is inactive given Z. | [02](notebooks/02_probability_for_biologists.ipynb) | [16](notebooks/16_bayesian_networks_independence.ipynb) |
| **Decision boundary** | The set of inputs where a classifier switches from one predicted class to another. | [08](notebooks/08_knn_naive_bayes.ipynb) | [08](notebooks/08_knn_naive_bayes.ipynb) |
| **Decision tree** | A classifier that asks a sequence of questions about features; each leaf predicts a class. | [00](notebooks/00_welcome_ml_for_biology.ipynb) | [10](notebooks/10_decision_trees_random_forests.ipynb) |

| **Dirichlet prior / pseudo-counts** | Prior for categorical probabilities; its MAP estimate adds 'imaginary' counts and removes zero probabilities. | [05](notebooks/05_likelihood_mle_map.ipynb) | [08](notebooks/08_knn_naive_bayes.ipynb) |
| **Discriminative classifier** | Models P(Y∣X) directly (logistic regression, SVM, neural networks). | [00](notebooks/00_welcome_ml_for_biology.ipynb) | [09](notebooks/09_logistic_regression.ipynb) |

| **Entropy** | H = −Σ p log₂ p: the average number of bits needed to encode a draw; 0 for a pure set of labels, 1 bit for a 50/50 split. | [10](notebooks/10_decision_trees_random_forests.ipynb) | [10](notebooks/10_decision_trees_random_forests.ipynb) |
