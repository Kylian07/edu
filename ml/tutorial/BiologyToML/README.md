# From Biology to Machine Learning: from CMU 02-620 to the research frontier

A notebook-based course that takes a **first-year biology major** from "what is a genotype
matrix?" to a **deep, working understanding of CMU 02-620 *Machine Learning for Scientists*** —
and then on to the **machine learning behind current computational-biology research**: single-cell
and spatial omics, statistical genetics, regulatory genomics, protein language models and
structure prediction, generative design, molecular machine learning, causal inference from
perturbations, trustworthy ML, and AI agents for science.

The course has **45 executable Jupyter notebooks** in two levels:

- **Level 1 · the 02-620 core (Modules 00–23).** Every topic of the 02-620 lectures — regression
  and regularisation, classification (k-NN, naïve Bayes, logistic regression, trees, random
  forests, SVMs), clustering, mixture models and EM, PCA, Bayesian networks, Gaussian graphical
  models, hidden Markov models, Bayesian learning and MCMC, neural networks, model selection —
  taught completely inside the notebooks: definitions, derivations, worked examples, the
  important figures and the "what you should know" points, each with a 📘 *Lecture notes* summary.
- **Level 2 · the research frontier (Modules 24–43).** Twenty modules that reuse exactly the
  Level 1 ideas to reach current research, each implementing the core algorithm of a field from
  scratch and checking it against a known ground truth.
- **Capstone (Module 44).** A complete 02-620-style project plus a research-project studio with
  six frontier project tracks and a reproducibility checklist.

Every notebook runs on a free Google Colab CPU, derives every formula step by step (each
equation followed by an "*In words:*" reading), implements every algorithm in NumPy or PyTorch,
and uses **synthetic data generated by code** — the repository stores no datasets and no pictures
(see [`DATA.md`](DATA.md)).

**Start here:** [00 · Welcome: what machine learning does for biology](notebooks/00_welcome_ml_for_biology.ipynb)

## Who it is for and what you will be able to do

**Assumed background:** high-school algebra and introductory biology. No programming, calculus,
linear algebra or statistics is assumed: Part A teaches exactly the parts of the 02-620
prerequisites (02-601 *Programming for Scientists*, 02-680 *Essential Mathematics and Statistics
for Scientists*) that the course uses, at the moment they are needed. Level 2 assumes Level 1.

**After Level 1 you will be able to:**

1. Formulate a biological question as a learning problem — inputs X, outputs Y, the function f,
   supervised P(Y∣X) or unsupervised P(X) — and choose a method family for it.
2. Derive by hand the central results of 02-620: least squares as maximum likelihood, ridge as
   MAP, the lasso's soft-thresholding, naïve-Bayes counts, the logistic-regression gradient,
   information gain, the SVM margin and dual, k-means and EM updates, PCA as an eigenproblem,
   Bayesian-network factorisations, d-separation, variable elimination, Chow–Liu trees, the
   precision-matrix/conditional-independence identity, forward–backward, Viterbi and Baum–Welch,
   conjugate posteriors and Gibbs sampling, back-propagation and the bias–variance decomposition.
3. Implement each of these algorithms in a few dozen lines of NumPy, check it against
   scikit-learn/SciPy, and explain every number it prints.
4. Evaluate honestly: train/validation/test splits, cross-validation, nested CV, selection bias.

**After Level 2 you will also be able to:**

5. Explain the data, assays and artefacts of a research area (single-cell, spatial, multimodal,
   GWAS, regulatory DNA, protein families and structures, molecules, CRISPR perturbations).
6. Implement the core method of the field from scratch — negative-binomial GLMs, VAEs, attention,
   diffusion and flow matching, graph neural networks, Gaussian processes and Bayesian
   optimisation, batch integration, RNA velocity and optimal transport, mixed models and
   fine-mapping, sequence CNNs, Potts models, Kabsch superposition, conformal prediction, …
7. Validate methods against a simulated ground truth, provoke their failure modes on purpose
   (confounding, leakage, over-correction, shift, over-confident uncertainty), and read current
   papers knowing what each method changes and which questions are open.

## How every notebook works

All notebooks follow the repository's [tutorial specification](../../../guide/Tutorial_Creation.md)
and share one structure:

| Part of the notebook | What it gives you |
|---|---|
| Title, Colab badge, key-information table | hardware, frameworks, prerequisites, time; the 02-620 topics (Level 1) or the modules it builds on and the research frontier it covers (Level 2) |
| ⚠️ Important notes, 🎯 objectives, 🗺️ contents | what is simulated and what the hidden truth is; what you will be able to do |
| 🧫 The biological question | why a biologist should care, and which landmark study the module mirrors |
| Setup cells | hardware check, dependency check, seeds, and the 🧰 **course toolkit** |
| Numbered sections | 📍 where we are, 🧮 math refreshers, theory with equations **and** their "*In words:*" reading, runnable experiments |
| 🔍 What just happened? / ✏️ Your turn | interpretation of each result, then a change for you to make |
| 📘 Lecture notes (Level 1) | a self-contained summary of that part of the 02-620 lecture: definitions, key equations, a worked example, an exam tip |
| 📄 Research connection (Level 2) | what the research field does, what the notebook builds, where the frontier is, what to read next |
| 🧪 Ground-truth check · 🔗 Builds on · 🧭 From toy to real data | the method checked against the simulated truth; the Level 1 idea it extends; what changes with real data, public resources and production tools |
| 📌 Key takeaways · ✅ Checkpoint · 🧠 Questions · 🚀 Bonus · 📝 Lab note | summary, self-test with hidden answers, discussion, extensions, a lab-notebook template |
| 📚 References · ➡️ Next | full citations; the next module |

**Self-contained.** The notebooks teach the lecture content themselves; you never need the
lecture slides. **Honesty policy.** All data are simulated and labelled SIMULATED; each simulator
mimics a classic study or assay and returns its hidden truth, so you can see whether a method
found it. Notebooks report results honestly, including when a fancy method does not beat a
simple baseline.

## Shared conventions

| Convention | Value |
|---|---|
| Data matrix | `X` has **N rows = samples** (individuals, patients, cells) and **J columns = features** (SNPs, genes, proteins); where other texts use *n*, *K* or *p* for the number of features the notebook says so |
| Genotypes | 0/1/2 = copies of one allele (AA = 0, AT = 1, TT = 2) |
| Labels | `y ∈ {0, 1}` (SVM: −1/+1); 1 = disease/positive (e.g. AML, malignant) |
| Regression weights | `w` with intercept `w0` |
| Logarithms | `log` is natural; entropies use `log2` (bits) |
| Randomness | `SEED = 0`, `rng = np.random.default_rng(SEED)` in every notebook; `torch.manual_seed(SEED)` where PyTorch is used |

[`course_toolkit.py`](course_toolkit.py) (v2.0) holds the reference implementation of the shared
helpers: the synthetic look-alikes of the classic data sets, the frontier simulators, the small
worked-example tables (PlayTennis, the naïve-Bayes genotype table, the alarm network, the
two-dice HMM), metrics and plotting. **Each notebook contains a verbatim copy of the helpers it
needs**, so every notebook runs on its own in Colab.

## Data: everything is generated by code

The repository stores **no data files and no pictures**. Every data set and figure is produced
by code in the notebook, from the toolkit's simulators (fixed default seeds, so every notebook
sees the same data). The classic examples of 02-620 — the Golub leukaemia study, the Sachs
T-cell signalling study, the prostate-cancer study, the Wisconsin breast-tumour features, blood
cells, microscopy images — are replaced by **synthetic look-alikes** that reproduce their
structure and come with the hidden truth. Level 2 adds simulators of single-cell counts,
differentiation with spliced/unspliced RNA, spatial tissue, CITE-seq/ATAC, Perturb-seq, genotypes
with linkage disequilibrium, enhancer sequences with a motif grammar, protein families and
structures, and a small-molecule library. [`DATA.md`](DATA.md) documents each simulator, what it
mimics, what truth it returns and which modules use it.

## Running the notebooks

**Colab (recommended):** click the badge at the top of any notebook. No GPU is needed; every
notebook runs in a few seconds to about two minutes on a CPU (PyTorch, preinstalled on Colab, is
used by several Level 2 modules).

**Locally:**

```bash
cd ml/tutorial/BiologyToML
python -m pip install -r requirements.txt
jupyter lab notebooks/
```

**Check the whole course** (schema, structure, toolkit copies, links, no slide references, no
stored pictures or data; add `--execute` to run every notebook):

```bash
python validate_notebooks.py            # fast structural check
python validate_notebooks.py --execute  # also executes all 45 notebooks (≈ 30–60 min on a laptop CPU)
```

The notebooks are stored **without outputs**.
