## Reading progression (representative anchors)

1. **Algorithmic origins (2009–2013):** rotation invariance → volumetric matching → alignment → target segmentation → template-free detection. Use M01–M12.
2. **Deep-learning transition (2016–2020):** simulated crowds → CNN/autoencoder → de novo discovery → open sets → Gum-Net. Use M09–M20.
3. **Limited annotation and unsupervised discovery (2020–2025):** self-supervision → few-shot/active learning → domain shift → DISCA → CryoSAM/Vox-UDA → BOE-ViT → AITom. Use M13–M24.
4. **Recent frontiers (2026):** diffusion-feature multiscale segmentation, DUIL, score-based denoising, topology-preserving TopoFuse, RobPicker and knowledge-guided clustering. Use M18–M25.
5. **Biology-focused reading:** fungal plasma-membrane cryo-ET study. Use M01/M05/M09/M26 to trace a biological discovery rather than only machine-learning accuracy.

**Paper-level mastery assignment:** Identify the dataset (specimen/particle/tomogram/tilt-series), train/validation/test separation, evaluation metric, losses and controls; derive one equation and implement the closest toy component; compare against actual authors' code if published, citing exact version and deviations.
